# --- PyTorch ------------------------------------------------------------------

# The build that pip selects depends on the platform:
#   macOS    Apple silicon: a recent release, with GPU support (mps).
#            Intel: 2.2.2, the last release for it.
#   Linux    build with NVIDIA GPU (cuda) support; it also runs without a GPU.
#   Windows  CPU-only build.
# For another build (GPU on Windows, a smaller CPU-only download on Linux),
# first install torch and torchvision with the command given at
# https://pytorch.org/get-started/locally/ and then run the command above.
torch>=2.2
