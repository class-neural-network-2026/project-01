# Project 01: Variational Autoencoder

In this project you implement a variational autoencoder (VAE) in PyTorch and train it on a small subset of MNIST: the digits 0, 1, 2, 3, 4 as gray images of 32 x 32 pixels, without labels.

| Data | Images | File |
|---|---|---|
| training | 100 per digit (500 in total) | `data/mnist_train.pt` |
| testing | 1000 per digit (5000 in total) | `data/mnist_test.pt` |

Your trained model is measured on the test images by two values. For both, lower is better.

- **FID** (Frechet inception distance) between 5,000 images generated by your model and the 5,000 test images.
- **Reconstruction error**: squared difference between a test image and its reconstruction, summed over the pixels and averaged over the test images.

## 1. Get the code and the data

You need [Git](https://git-scm.com/downloads) and Python 3.11 or newer (on a Mac with an Intel processor: 3.11 or 3.12).

Clone the repository and move into its folder:

```bash
git clone git@github.com:class-neural-network-2026/project-01.git
cd project-01
```

This address uses SSH and needs an SSH key registered in your GitHub account. Without one, use HTTPS instead:

```bash
git clone https://github.com/class-neural-network-2026/project-01.git
```

The repository contains the code and the data:


## 2. Set up the Python environment

Run these commands in the `project-01` folder. They create a virtual environment in the folder `.venv`, activate it, and install the packages.

macOS and Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Activate the environment again every time you open a new terminal (the second command).

Notes:

- The installation downloads PyTorch, which is large; it can take several minutes.
- On Windows, pip installs a CPU-only build of PyTorch. To use an NVIDIA GPU, first install `torch` and `torchvision` with the command given at <https://pytorch.org/get-started/locally/>, then run the last command above.
- The notebook uses an NVIDIA GPU (`cuda`) or the GPU of an Apple silicon Mac (`mps`) when there is one, and the CPU otherwise.

## 3. Open the notebook

Use one of the two:

- **Browser**: run `jupyter notebook` in the `project-01` folder with the environment activated, and open `assignment_01.ipynb`.

## 4. Do the assignment

Write the five files of the `code` folder. Every part to write is marked with `TODO`, and the docstring of each function specifies its inputs and outputs.

| File | What you write |
|---|---|
| `code/myinfo.py` | your name and student ID |
| `code/mymodel.py` | the VAE: encoder, reparameterization, decoder |
| `code/myoptim.py` | batch size, number of epochs, optimizer |
| `code/mytrain.py` | loss function, training for one epoch |
| `code/mysample.py` | generation of new images |

Rules:

- Keep the interfaces (names, inputs and outputs of the functions) unchanged: the notebook relies on them.
- Do not modify `assignment_01.ipynb`, the files in `util`, or the files in `data`.
- Train with the training images only. The test images are for the evaluation at the end of the notebook.
- The architecture of the VAE, the optimizer and its settings, the batch size and the number of epochs are your choices: try to make the FID and the reconstruction error as low as you can.

Then run the notebook from top to bottom with *Restart* and *Run All*. It stops with an error message at the first part that is not written yet or does not have the expected interface. When it runs to the end, it has saved:

| File | Content |
|---|---|
| `train/loss.png` | training curves |
| `train/model.pt` | trained model |
| `sample/sample.png` | images generated by the trained model |
| `result/reconstruction.png` | test images and their reconstructions |
| `result/result_<student ID>_<name>.csv` | FID and reconstruction error |

About the last section of the notebook (results):

- The first run downloads the network used by the FID (about 100 MB), so it needs an internet connection.
- It takes seconds with a GPU, but can take more than 10 minutes with a CPU.
